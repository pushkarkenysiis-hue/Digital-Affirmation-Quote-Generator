# Digital Affirmation Quote Generator
A simple web application that generates uplifting digital affirmation quotes to inspire positivity and motivation. Users can click a button to receive a random affirmation, making it a great tool for daily encouragement. 
<br>
<ul>
  <p>Features:</p>
  <li>Randomly generates affirmation quotes</li>
  <li>Clean and minimal UI</li>
  <li>Responsive design (works on desktop and mobile)</li>
  <li>Easy to customize with your own quotes</li>
</ul>
<br>
<ul>
  <p>Usage:</p>
  <li>Open the webpage in a browser.</li>
  <li>Clean and minimal UI</li>
  <li>Click the Generate Quote button.</li>
  <li>Enjoy a new affirmation each time.</li>
</ul>
<br>
To add new affirmations, edit the quotes.js file and include your own phrases in the array.
